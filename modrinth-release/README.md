# Reverie 0.1.0 Modrinth release kit

This folder contains the files and copy needed for a manual Modrinth release:

- `reverie-0.1.0.jar` — upload as the version's primary file.
- `reverie-0.1.0.jar.sha256` — local integrity checksum.
- `PROJECT_DESCRIPTION.md` — project page body.
- `VERSION_CHANGELOG.md` — version-specific changelog.
- `UPLOAD_CHECKLIST.md` — fields, compatibility choices, and final QA steps.

The project has not been uploaded automatically because publishing requires the owner's Modrinth account, project ownership choices, public links, and final moderation submission.

No generated artwork is included. Add a hand-made project icon before publishing if desired; gallery images are optional.
